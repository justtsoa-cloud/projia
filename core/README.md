# tontolo (cœur Python)

Cœur du hub d'IA libre [Tontolo](https://github.com/raantss18/tontolo) : catalogue en ligne,
routage vers le meilleur modèle gratuit, bascule sur quota, serveur compatible OpenAI, agent
et MCP.

```bash
pip install "tontolo[linux]"
tontolo catalog list --free --category code
tontolo serve
```
