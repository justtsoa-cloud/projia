# projia (cœur Python)

Cœur du hub d'IA libre [Projia](https://github.com/justtsoa-cloud/projia) : catalogue en ligne,
routage vers le meilleur modèle gratuit, bascule sur quota, serveur compatible OpenAI, agent
et MCP.

```bash
pip install "projia[linux]"
projia catalog list --free --category code
projia serve
```
