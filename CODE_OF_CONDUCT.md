# Code de conduite

Ce projet adopte le [Contributor Covenant 2.1](https://www.contributor-covenant.org/fr/version/2/1/code_of_conduct/).

En résumé : soyez respectueux, bienveillant et constructif ; aucun harcèlement ni
discrimination ne sont tolérés. Les signalements se font de façon privée via le
signalement de sécurité GitHub du dépôt ; ils sont traités avec confidentialité.
